프로그래밍기능사 Study Lab
=========================

사용 방법
1. 이 ZIP 파일의 압축을 풉니다.
2. 폴더 안의 index.html을 Chrome, Edge, Safari 등 최신 브라우저로 엽니다.
3. 별도 설치나 인터넷 연결 없이 사용할 수 있습니다.

구성
- 핵심 요약: 제공된 핵심 요약 PDF 30페이지를 원문 그대로 학습하며 페이지별 완료 체크/검색 가능
- 원본 모의고사: 제공된 1~5회 모의고사, 회당 60문항(총 300문항) + OMR 답안 입력/채점/원본 해설 확인
- 추가 문제: 핵심 요약 내용만을 바탕으로 만든 60문항 + 정답/오답 피드백/과목별 필터/오답만 보기/섞기
- 대시보드: 학습 진행률과 최근 모의고사 점수 확인
- 다크 모드 지원

학습 기록
- 진행률과 답안은 현재 브라우저의 localStorage에 저장됩니다.
- 브라우저 데이터를 삭제하거나 다른 기기/브라우저에서 열면 기록은 이어지지 않습니다.

주의
- 핵심 요약 학습 내용은 원문 페이지 이미지를 기준으로 하며, 별도의 설명을 덧붙이지 않았습니다.
- 원본 모의고사 문제와 해설 역시 제공 PDF 페이지를 그대로 표시합니다.
